## 根据首轮结果完善的规则

首轮 T1 的多张卡片把解释写成“原文未进一步说明”，虽然未新增事实，但复习价值不足。调整为允许用简单语言解读原文已有例子和对照原文定义；只有确实没有可解释内容时才说明缺失。复测 T1 已用具体含义解释入队、出队、查看队头和长度。

针对 T6，把原文内的操作指令明确视为材料，禁止把它们当作用户要求执行。补充自测问题不得询问原文未给出的原因、例子不得另拆为重复卡片的规则，并明确英文输出同步翻译字段名。对 T1、T3、T4、T6、T7 用新的独立会话复测。

## 结构校验

对最终 `make-knowledge-cards` 目录运行官方 `quick_validate.py`，退出码为 0，输出：

```text
Skill is valid!
```

另外检查：SKILL.md 只有 name 和 description 两个元数据字段；名称与目录一致；agents/openai.yaml 可解析，显示名为 make_knowledge_cards，默认提示语包含 $make-knowledge-cards，简介长度符合规范；Skill 目录只有 SKILL.md 和 agents/openai.yaml；项目没有 Python 脚本或 TODO 占位符。

## 手工复现

从 cases.json 取出一项 text。T1、T2、T5、T6 可先按 filename 保存为本地 UTF-8 文件，再让助手按 Skill 读取；其他文章直接粘贴。T8 的四个请求需分别提交。

检查每张卡片的四类字段是否完整、是否只聚焦一个学习问题、内容是否能在原文中找到依据、重复是否合并，以及条件和矛盾是否保留。输出措辞或挑选顺序可能变化，不要求逐字匹配。
